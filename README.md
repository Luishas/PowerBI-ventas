# Dashboard de Ventas

## Descripción
Este proyecto es un **Dashboard interactivo de ventas** desarrollado en **Power BI**. Permite visualizar información de ventas por sucursal, producto, canal de venta y periodo de tiempo, ayudando a identificar tendencias y oportunidades de negocio.  

---

## Contenido
- `Ventas.pbix` → Archivo principal de Power BI con todas las visualizaciones y datos de ejemplo.
- `README.md` → Este archivo con la descripción del proyecto.
- `Assets/` → Capturas de pantalla o imágenes de apoyo para el portafolio.

---

## Funcionalidades principales
- Análisis de ventas por sucursal y zona.
- Comparación de ventas por producto y canal.
- Visualización de tendencias temporales y patrones de consumo.
- Gráficos interactivos filtrables por diferentes categorías.
- Indicadores clave de desempeño (KPIs) por país, ya que los datos son de una empresa multinacional. Permitiendo la rápida acción en la zona y país que lo necesite.

---

## Tecnologías utilizadas
- **Power BI Desktop** para creación del dashboard.
- **Archivos Excel / CSV** de ejemplo para los datos de ventas (si aplicable).

---

## Cómo abrir el proyecto
1. Descargar el archivo `Ventas.pbix`.
2. Abrirlo con **Power BI Desktop**.
3. Explorar las diferentes visualizaciones y filtros interactivos.
